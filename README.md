# data-visualization
Estudo dos fundamentos da percepção visual humana aplicados à representação e interpretação de dados

A visualização de dados é o processo de representar dados em formato gráfico. Ela ajuda a identificar tendências, acompanhar KPIs e descobrir padrões que impulsionam o seu negócio.

Com as ferramentas certas de visualização de dados, até mesmo os dados mais complexos se tornam fáceis de explorar. Essas ferramentas revelam conexões ocultas entre variáveis, permitindo que você aprofunde sua análise e torne as percepções mais intuitivas e acessíveis a todos.

Por exemplo, pense no seu desempenho de vendas. É claro que você pode ter dados que mostram a receita total e os negócios fechados. Mas, ao visualizá-los, digamos, com um gráfico em funil ou um mapa de calor, você consegue ver onde os negócios estão ficando estagnados, quais regiões estão apresentando melhor desempenho e onde as oportunidades podem estar escapando.

De repente, a história por trás dos números fica mais clara.
